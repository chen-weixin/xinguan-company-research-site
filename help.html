使用帮助

从安装、配置大模型到生成和导出报告，按下面的顺序操作即可。遇到问题时，先根据页面提示确定是数据、模型还是网络环节失败。

帮助目录安装与启动大模型设置开始企业研究进度与资料报告与 PDF历史研究软件更新故障排查

一、安装与首次启动

  1. 在软件下载页下载 Windows 安装包。
  2. 双击安装包，按提示完成安装。
  3. 从桌面或开始菜单打开“鑫观点企业研究”。
  4. 等待企业研究服务启动完成，再进行大模型设置。
软件面向 Windows 10/11 64 位系统。首次启动可能被 Windows 安全提示拦截，请确认安装包来自本站并核对 SHA-256 后再继续。

二、配置大模型

企业研究中的多轮推演和报告撰写需要调用大模型。点击左侧“大模型设置”展开配置。

字段填写内容
服务商选择你实际购买 API 的平台；兼容平台可选择“自定义”。
base_url服务商提供的 API 地址，不要填写模型网页地址。
api_key服务商后台生成的 API Key。不要发送给他人。
model填写服务商当前可用的准确模型名称。
temperature通常保留默认值即可。
  1. 完整填写服务商、地址、API Key 和模型名称。
  2. 点击“保存设置”。
  3. 看到“大模型已准备好”后，点击“测试连接”。
  4. 测试成功后即可开始企业研究。
API Key 保存在用户自己的设备中。本站和订阅服务不会要求用户提交大模型 API Key。模型调用费用由用户直接向模型服务商承担。

常见模型连接问题

  • 401/鉴权失败：API Key 错误、失效或复制时带入空格。
  • 404/模型不存在：模型名称或 base_url 不正确。
  • 429/额度不足：账户余额、并发或周期额度不足。
  • 连接超时：网络不稳定、服务商响应慢或地址无法访问。

三、开始企业研究

  1. 在“只需填写股票代码”处输入 6 位 A 股代码，例如 600519。
  2. 点击“开始企业研究”。
  3. 确认本周免费额度或当前订阅权益。
  4. 保持软件运行，等待资料采集、同行核验、多轮推演和报告生成完成。

系统会先识别企业的业务、行业和研究重点，再选择同行及补采资料。不同企业的讨论议题、报告章节和图表会有所不同。

四、查看进度和资料量

研究页面会显示当前正在做什么、已获取多少资料、已完成多少环节、剩余环节以及时间估算。资料统计按类型累计，不应在切换阶段时归零。

  • 绿色：该环节已经完成。
  • 金色：当前正在执行。
  • 灰色：尚未开始或本次不适用。

可以暂停、继续或停止研究。网络短暂失败时，系统会保留已完成阶段；关键资料不足或模型推演失败时，应明确显示失败原因，而不是生成低质量报告。

五、阅读报告与导出 PDF

研究成功后，页面只展示一份正式报告成品。资料统计和研究过程作为参考区存在，不会重复进入导出的 PDF。

  • 报告标题为企业简称加一句话核心结论。
  • 图表插入支持其结论的正文位置。
  • 资料来源和证据附录位于文章后部。
  • 封面和免责声明会注明 AI 生成、模型差异与非投资依据。

点击“导出 PDF”即可下载。若导出失败，先确认报告已完整生成，再根据错误提示检查字体、渲染服务或磁盘空间。

六、历史研究

左侧“历史研究”显示企业简称、股票代码和短日期。点击记录可重新打开同一份报告；点击右侧“×”可删除指定记录。删除后不可恢复。

七、软件更新

软件启动后会自动检查新版本。没有更新时不显示更新卡片；发现更新时点击“立即更新”，安装完成后重新启动软件。

也可以在软件下载页查看当前公开版本和更新内容。

八、故障排查

提示“企业研究服务未连接”

完全退出软件后重新打开，等待服务启动；若仍失败，检查安全软件是否拦截程序组件。

资料长时间没有变化

观察当前环节和预计时间；若单一环节明显超时，可停止后重新研究。重复失败时记录股票代码、失败环节和页面错误信息。

关键资料不足

系统会自动更换来源并重试。多轮补采后仍不足时会停止并列出缺失资料，不应生成报告。

大模型快速返回一篇很短的报告

这通常意味着模型服务异常、输出被截断或研究推演未完整完成。系统应将其判定为失败，请检查模型连接和额度后重试。
